🔑 Google Gemini API Key

You can either save your key directly in your project's .env file or set it dynamically below.

📚 How to Get a Free Gemini API Key

  1. Visit the official Google AI Studio.
  2. Sign in with your Google account.
  3. Click "Create API key" in the top-right corner.
  4. Choose a Google Cloud project (or create a new free one automatically).
  5. Copy your generated key and paste it into the field above or set GEMINI_API_KEY=your_key in your .env file.
